一、GPT 部署

chatgpt 本地端部署

诉求点：能够本地部署，以缓解其他端收费的情况，且能够后续整合进工作流。

可能的问题：

  • 需要代理，无法直接访问

待评估：

  • https://github.com/Licoy/ChatGPT-Midjourney 混合两者功能，但是相对超过需求了
  • https://github.com/Yidadaa/ChatGPT-Next-Web 相对简洁
  • https://github.com/yakGPT/yakGPT 整合了语音，没有prompt？
  • https://github.com/Lovelearningxi/Chat-gpt_streamlit 适合放在外部同步的，但是好像没有鉴权？
  • https://github.com/cogentapps/chat-with-gpt 带语音功能
  • https://github.com/elevenlabs/elevenlabs-python 语音的python脚本

代理：

  • https://github.com/PawanOsman/ChatGPT 直接代理，但是安全性存疑
  • https://github.com/x-dr/chatgptProxyAPI 辅助代理，需要自己部署
  • https://github.com/barretlee/cloudflare-proxy 小胡子哥的
  • https://github.com/gaboolic/vercel-reverse-proxy vercel
  • https://github.com/gaboolic/cloudflare-reverse-proxy cloudflare

已评估：

  • https://github.com/mckaywrigley/chatbot-ui 太丑了界面，ui引导一般
  • https://github.com/Yidadaa/ChatGPT-Next-Web 线上部署本地
  • https://github.com/barretlee/cloudflare-proxy 部署成功，openai.kuhung.me

部署

部署 chatgpt-next-web

docker pull yidadaa/chatgpt-next-web

docker run -d -p 5001:3000 \
  --name chatgpt-next-web \
  -e OPENAI_API_KEY="sk-YOUR_OPENAI_API_KEY" \
  --restart=always \
  yidadaa/chatgpt-next-web
  
  
  
docker run -d -p 5001:3000 \
  --name chatgpt-next-web \
   -e CODE="gpt9527" \
  --restart=always \
  yidadaa/chatgpt-next-web

# 由于portainer有时间保护机制，过期需要重启，所以似乎没必要restart always
docker run -p 9000:9000 -p 8000:8000 --name portainer \
--restart=always \
-v /var/run/docker.sock:/var/run/docker.sock \
-v /mydata/portainer/data:/data \
-d portainer/portainer

docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/data portainer/portainer-ce:latest

docker inspect --format='{{.Name}} {{.HostConfig.RestartPolicy.Name}}' $(docker ps -aq)
sudo lsof -i :8080 | awk 'NR!=1 {print $2}' | xargs sudo kill
