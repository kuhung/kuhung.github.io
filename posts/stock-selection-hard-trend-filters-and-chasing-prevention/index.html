在上一篇《个人量化选股（二）：标的池怎么选，以及多路召回与双轨粗排》中，我们通过流动性客观门槛与全景行业 ETF 雷达，把全市场的数千只股票压缩到了单市场 100 只高信息密度的物理观察池（中国资产 100 只 + 美股 100 只，合计 200 只）。

这也是我最近在 QuantFull 整理的「个人量化选股实战体系」的第三篇。标的进入观察池之后，我们面对的是一个更根本的选拔逻辑：面对这 100 只标的，我们究竟该用什么规则决定买入？

很多个人投资者习惯停留在「凭感觉买」的感性模式：看分时拉升跟风追入、看跌多了凭直觉抄底。这种凭感觉交易的决策链条没有一致的规则，极易受到处置效应支配（赚蝇头小利就跑、深度套牢死扛），长期处于负期望博弈。

要走出凭感觉买的随机性，我们需要一套具有统计正期望的客观规则。我们先通过全景图谱，把选股流派抉择、动量运行机理与顺逆风环境做一次全局透视：

从图中的全局对照中，可以提炼出三个底层事实：

  1. 为什么选趋势动量：基本面价值流存在财报滞后与阴跌陷阱，多因子量化对冲要求分散持有数百只标的、个人有限资金的佣金滑点会吃光超额。趋势动量（Jegadeesh & Titman 1993, Asness 2013）顺应大资金分批建仓带来的持续价格漂移，且强趋势标的上方没有套牢盘抛压阻力。个人资金在中大盘标的（日均成交额 > 5,000 万元）中几乎零冲击成本，能充分发挥小资金进出果断的机动性优势，靠非对称的高盈亏比让利润奔跑。
  2. 何时顺风，何时逆风：趋势动量极佳的适用期是产业大主线明朗的结构性牛市（如 2020-2021 新能源、2023-2024 美股 AI 硬件）；它的典型逆风期是存量博弈下的高频均值回归震荡市（频繁突破容易遭受锯齿损耗 Whipsaw Loss）以及极端超跌脉冲诱发的动量崩溃（Momentum Crash）。
  3. 动量绝不能盲目套用：很多人转向动量后，习惯直接把观察池按涨幅从高到低排序挑前几名买入。这会直接撞上动量策略的两大经典失效陷阱：弱势超跌反抽（大跌破位后的非平稳反弹，上方堆积密集的被动解套抛售压力）与情绪加速赶顶（短期严重脱离中长期持仓成本线，极易买在均值回归前夕的波段高点）。

动量指标只衡量过去一段时间上涨的速度，它不负责判断标的当前所处的趋势位置和风险收益比。

门槛一：为什么动量股必须在 MA200 年线上方

动量指标衡量的是股票在过去一段时间里涨得有多快。它是一个关于速度的指标，但它不负责判断股票当前所处的位置。

这里最常见的陷阱，就是大跌之后的死猫反弹。

假设一只股票在过去一年从 100 块跌到了 20 块，然后在最近两个月从 20 块快速反弹到了 35 块。短期涨幅高达 75%，如果纯看相对速度，它会直接冲进全市场动量榜单的前三名。但从长期走势看，它依然被压制在 200 日线下方，上方堆积了过去一整年被套牢的巨量筹码。

买入这种股票，本质上是在长线下跌通道里左侧逆势承接抛压。每次反弹到阻力位，就会遭遇持有者的密集解套抛售。

200 日均线反映的是场内过去大约 10 个月到 1 年交易者的加权平均持仓成本线。收盘价站上 200 日线，说明中长期持有者的平均筹码开始进入浮盈状态，抛压减弱，支撑有效。

门槛二：为什么偏离 200 日线超 30% 坚决不追

确认了股票在 200 日线上方之后，并不是说偏离均线越远越好。

当一只股票的价格距离它的 200 日线超过 +30%、甚至 +50% 时，说明短期内价格脱离了基本面的平稳积累，进入加速赶顶或过度炒作阶段。

价格偏离长期成本线过远时，均值回归的压力会非线性增大。在偏离 40% 的位置发出买入指令，极容易买在短期波段的最高点，随后遭遇大幅均值回归回踩。

为了量化这种风险，我们统计了观察池历史滑动窗口样本，按照买入时距 MA200 的乖离率（$\text{Bias} = P / \text{MA200} - 1$）划分为五个区间，测算其在未来 60 个交易日内的最大回撤分布：

数据表明：当偏离度处于 0%~+15% 时，未来 60 天平均回撤仅 -7.8%，P90 极端回撤仅 -19.5%。

一旦偏离度跨过 +30%，平均最大回撤扩大到 -12.6%，P90 极端回撤直接跳跃到 -26.2%；若偏离超过 +50%，极端回撤深达 -38.7%。

基于这个客观分布，系统设定了一条防追高硬规则：

$$\text{Bias} = \frac{\text{最新收盘价}}{\text{MA200}} - 1 \le +30%$$

只要正向偏离度超过 30%，哪怕其他所有指标排第一，系统也会标明「超温过热，暂不追高」，强制跳过该标的，名额按顺序顺延给下一名（Graceful Skip）。

在最新 200 只池的实盘数据中：

  • 超威半导体 (US.AMD)：在美股候选池中位列前列，1 年卡玛比率达 4.52，12-1 动量达 +138.7%。但现价距 MA200 年线偏离达 +34.1%，超过 +30% 警戒线。系统判定「不买：距 200 日线 +34.1%，超过 +30%，不追高」，名额顺延给下一顺位优质标的。
  • 联想集团 (HK.00992)：在港股龙头中 12-1 动量高达 +182.7%，但距年线偏离高达 +49.5%，触发防追高拦截；
  • 戴尔科技 (US.DELL)：动量高达 +289.5%，距年线偏离 +44.5%，同样触发拦截。

这条规则放弃了一小段非理性的末端赶顶利润，换取了整个组合免于承受接近 30% 到 40% 的极端回撤。

门槛三：为什么 12-1 动量要剔除最近 1 个月

在计算动量时，我们采用的不是过去一整年的总涨幅（12-0 动量），而是 12-1 动量：

$$\text{Mom}{12-1} = \frac{P{t-21}}{P_{t-252}} - 1$$

也就是用 21 个交易日（约 1 个月）前的收盘价，除以 252 个交易日（约 1 年）前的收盘价，把最近 21 天的数据剔除。

这样做背后的计量金融学依据，来自经典金融实证研究（Jegadeesh & Titman, 1993）：

  • 在 3 到 12 个月的时间跨度上，股票截面收益表现出显著的动量效应（Momentum Effect），即过去表现好的股票在未来一段时间继续跑赢；
  • 在 1 个月以内的短期跨度上，股票截面收益表现出显著的短期反转效应（Short-Term Reversal），即短期暴涨的股票在未来 1 到 4 周往往伴随获利回吐与买卖价差回弹。

我们在 200 只观察池的历史月度截面上做了检验：近 1 个月收益率对未来 1 个月收益率的 Rank IC 为 -0.0757，表现出明确的负相关反转特征。

如果不剔除最近 21 天，直接算过去一整年的涨幅，最近一个月暴涨的标的会被赋予最高权重。在实际交易中，短线脉冲往往伴随着微观结构上的流动性耗竭与短期均值回归回踩。

把最近 21 天剔除之后，指标衡量的是剥离了短线噪音之后的中期趋势强度。

在最新 200 只池的实盘数据中：

  • 比特币现货 ETF (US.IBIT) 与 以太坊现货 ETF (US.ETHA)：短期在场内情绪带动下快速反弹，价格站上了 200 日线上方（分别偏离 +10.4% 与 +8.0%）。如果只看短期突破，容易误判为主升浪启动。计算 12-1 动量时，扣除近 1 个月后，IBIT 的 12-1 动量为 -25.1%，ETHA 为 -31.9%，说明其中期依然处于下行修复阶段。系统准确判定为状态②高位滞涨，发出「12-1 动量为负，还在下跌」的拦截提示，避免了过早建仓。

核心实现代码

以下是生产环境中负责准入门槛检验的向量化 Python 实现：

from typing import Dict, Optional, List
import numpy as np

def calc_momentum_12_1(closes: List[float]) -> Optional[float]:
    """计算 12-1 相对动量: P(t-21) / P(t-252) - 1。
    
    若历史不足 252 根日 K 但满 126 根（6个月），回退到近 6 个月收益率兜底。
    """
    if len(closes) >= 252:
        base = closes[-252]
        if base > 0:
            return float((closes[-21] / base - 1.0) * 100.0)
    elif len(closes) >= 126:
        base = closes[-126]
        if base > 0:
            return float((closes[-1] / base - 1.0) * 100.0)
    return None

def buy_gate_reason(
    p_last: float,
    ma200: Optional[float],
    mom_12_1: Optional[float],
    max_gap_pct: float = 30.0
) -> str:
    """三道买入硬门槛过滤。满足条件返回空字符串，否则返回具体拦截原因。"""
    if ma200 is None or mom_12_1 is None:
        return "数据样本不足，不满足计算条件"
    
    bias_pct = (p_last / ma200 - 1.0) * 100.0
    
    # 门槛①：周期生命线
    if bias_pct <= 0:
        return f"收盘在 200 日线下方（{bias_pct:+.1f}%），一票否决"
    
    # 门槛②：动量转正
    if mom_12_1 <= 0:
        return f"12-1 动量为负（{mom_12_1:+.1f}%），还在下跌"
    
    # 门槛③：防追高警戒
    if bias_pct > max_gap_pct:
        return f"距 200 日线 {bias_pct:+.1f}%，超过 +{max_gap_pct:.0f}%，不追高"
    
    return ""

阶段小结

这三道准入硬门槛解决的是买入端的基本安全问题：

  • 不在下行通道里左侧逆势接盘（MA200 过滤，在 200 只全景池中拦截了 111 只破位/反弹标的）；
  • 不被 1 个月的短线波动误导（12-1 动量剔除短期反转噪声，拦截了 13 只高位滞涨标的）；
  • 不在情绪过热的顶部接盘（+30% 乖离率拦截，在 200 只全景池中拦截了 13 只过热加速标的）；
  • 从全量 200 只观察池中最终筛选出 63 只合格标的（通过率 31.5%）。

下一篇我们要讨论的是：在通过了这三道硬门槛的 63 只合格标的里，各市场内部到底用什么指标进行截面精排（美日市场的卡玛比率 vs 港 A 市场的相对动量）、同一家公司在 A/H 两地上市时如何用溢价中位数仲裁择优，以及为什么在历史回测中取消了行业硬上限。
