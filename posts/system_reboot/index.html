2. NVIDIA 驱动安装

  • 步骤：
    1. 添加 NVIDIA 驱动程序 PPA： 
      sudo add-apt-repository ppa:graphics-drivers/ppa
    2. 更新软件包列表： 
      sudo apt-get update
    3. 安装 NVIDIA 驱动程序： 
      sudo apt-get install nvidia-driver-xxx
      （将 xxx 替换为具体版本号）
    4. 重启系统： 
      sudo reboot
    5. 测试安装： 
      nvidia-smi
  • 注意：驱动程序的安装和配置可能因不同显卡型号和 Ubuntu 版本而有所不同。

5. Docker 更改安装位置

  • 步骤：
    1. 停止 Docker 服务： 
      sudo systemctl stop docker
    2. 备份 Docker 数据： 
      sudo tar -czvf docker-backup.tar.gz /var/lib/docker
    3. 移动 Docker 数据目录： 
      sudo rsync -axP /var/lib/docker /home/kuhung/docker-data/
sudo mv /var/lib/docker /var/lib/docker.old
sudo ln -s /home/kuhung/docker-data/docker /var/lib/docker
    4. 启动 Docker 服务： 
      sudo systemctl start docker
    5. 验证新位置： 
      docker info | grep 'Docker Root Dir'

8. 挂载 Windows 分区

  • 步骤：
    1. 确认 Windows 分区： 
      sudo fdisk -l
    2. 创建挂载目录： 
      sudo mkdir /media/windows
    3. 挂载 Windows 分区： 
      sudo mount -t ntfs /dev/sdaX /media/windows
    4. 卸载分区： 
      sudo umount /media/windows
    5. 自动挂载： 
      sudo nano /etc/fstab
/dev/nvme0n1p6 /home/kuhung/data_n1p6 ntfs defaults 0 0
/dev/nvme0n1p8 /home/kuhung/project_n1p8 ntfs defaults 0 0

11. 文件共享

  • 在 Ubuntu 上安装 Samba： 
    sudo apt update
sudo apt install samba
  • 配置 Samba： 
    sudo nano /etc/samba/smb.conf
    • 添加共享配置： 
      [SharedFolder]
path = /path/to/shared/folder
read only = no
guest ok = yes

17. Git 相关

  • 重命名分支：
    1. 切换到其他分支： 
      git checkout <其他分支>
    2. 重命名分支： 
      git branch -m <旧分支名> <新分支名>
    3. 推送更改到远程： 
      git push origin :<旧分支名>
git push origin <新分支名>
  • 删除分支：
    • 删除已合并的分支： 
      git branch -d <branch_name>
    • 强制删除未合并的分支： 
      git branch -D <branch_name>

19. Conda

  • 创建环境并安装包： 
    conda create -n automl python=3.10
pip install torch==1.13.1+cpu torchvision==0.14.1+cpu -f https://download.pytorch.org/whl/cpu/torch_stable.html
pip install autogluon
  • 创建临时环境： 
    conda create -n temp python=3.9
pip install tensorflow==2.9.0
pip install autokeras==1.0.19
conda remove -n temp --all
