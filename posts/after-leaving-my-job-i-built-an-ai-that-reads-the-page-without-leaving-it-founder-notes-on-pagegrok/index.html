离职后，我用 AI 做了个「不跳转网页」的产品：PageGrok 创始手记

为什么做插件

PageGrok 是我离职以来，一个真正意义上的产品。去年折腾了不少时间做量化、做视频、写东西，东研究一个、西研究一个，做下来发现还是需要一个具体形态的产品来跑通整条链路。（之前多是 web 网页）。

最大的启发来自同期离职的一位同事。她在中东，自己做了一个浏览器插件，反响还不错。我之前的经验集中在机器学习、算法、数据管线上，服务的无非是运营和用户增长业务。需要一个产品跑通来验证想法，浏览器插件是个不错的选择：入口轻，开发周期短，用户触达直接。

毕竟工作的大部分时间也是在网页里过的。每天都会打开网页处理事情，无论是外部资料还是内网知识库（KM）上的内容，在 AI slop 流行的同时，信息过载了。很自然就想到让 AI 来解读。别人用 AI 扩写，你再用 AI 总结，完成了一轮社会结构意义上的编码和解码。

出发点就是：不想再跳转网页，就在旁边看。

功能设计

项目 3 月份开始。那时刚好从 Cursor 往 Codex 和 Claude 过渡，让 Claude 帮我写了一版，很快就有了一个带着 AI 味儿的原型。

调研过竞品 Page-Assist。它想做的是网页上的对话框，一个 chatbot。但 chatbot 是 23、24 年的形态了，而且复杂。切入点就是做简单一点。

自己用的时候发现，GitHub、Twitter、小红书这类复杂站点，整页读进来不加限制，重点容易丢掉。左右侧边栏塞了不少无关内容。当时一个产品直觉：能不能借鉴印象笔记的框选功能，选中想要的区域再做解读。提示词也按这个方向写，完成得还不错。

核心功能就几点。启动后，把当前网页内容读进来，跟它交互拿到想要的东西。觉得取的内容不准，也可以自己框选。

跑了几个小版本后发现，有时候我自己也不知道想问什么。典型的冷启动问题：用户不知道该干什么时，得先告诉他可以干什么。借鉴了 Google「问问 Gemini」侧边栏的引导式提问，一启动给出三个推荐问题。再往后是更细节的事：这三个问题要不要让用户自定义，愿不愿意用自己的模型来读。

技术选型

不跳转网页这个点，后来延伸出另一层：隐私。

不少同类产品走的是第三方服务。无论是个人还是小型公司，都不希望资料跑到外面去。当时我在本地 Mac 和 Ubuntu 服务器上都部署了 Gemma 4，做一些小总结，效果还不错。为此还做过小模型本地推理的 benchmark，搭了 Traktoken 来看模型框架的首字响应、吞吐量、负载情况，测评过程写在 拒绝感觉有效，基于在线推理性能测评，选出最适合我 Mac 的 LLM 推理框架。

但用得久了碰到一个问题。Ubuntu 上的 Gemma 4 冷启动要十秒以上，体验很差。脑子转得很快，却要冷静几秒钟，接受不了。

恰好这时接触到 Cerebras。和英伟达路线不同，他们做的就是一个「快」字。据说是在整块晶圆上做模型服务，首字延迟和吞吐量都很惊人，能在一秒内完成回答。当时试用了平台上的 Gemma 4，就是我想要的。后来本地服务就没怎么用了。我自己的隐私需求其实不算特别强，也没有特别敏感的企业向内容。

推广与定价

一开始把内容发在了 V2EX。从后面做 SEO 的角度看，这个举动确实带来不少曝光。但当时定调强调本地隐私，后面想接自己提供的 API 服务时，AI 生成的内容摘要极度偏向隐私，导致受众十分窄。后来改过几次网站，想在 SEO 上把它掰回来。近期流量看，有一点效果，总比没有强。

免费提供插件，有人用，至少证明有需求。中间一度 Chrome 后台显示有 5000 用户。但那次很奇怪，是某个特定版本上的短时高峰。升级后这些设备并没有跟着升版本，推测可能是内部服务或黑灰产爬虫，后来当异常数据剔掉了。

后来补了账号体系。定价参考 Cursor 旧套餐：5 美元 500 次/月。按最近的测试，次数可能偏多了，或者计费周期该拉长一点。月均消耗大概一两百次。高频用户的情况不清楚，但插件本身的使用频次就不会特别高。

我的用法

现在的工作流是：解读完网页，把回复复制下来。复制做了两种：只复制回答，或复制整段对话。这是自己用深了之后总结出来的设计。我需要把原始链接、我的问题、它的回答一起带上。后面做选题或知识集成时，能知道当时问了什么、得到了什么，还能回看原文。复制之后可以存到苹果备忘录，我现在是用脚本直接传到 GitHub Gist。后面其他 AI 也能读到这些 case，再接到选题、产品导向和文档输出里。

整体做下来，产品出发点、宣传、商业闭环，这条链路是走完了。但如果再做一次，可能会多想商业化，而不是只做自我实现。目前每周用户数为54，这些都是自然流量带来的，说明需求存在。如果你也要总结页面，又不想丢给豆包或其他 AI，或者转发链接碰到登录鉴权，可以试试打开侧边栏让 AI 解读当前网页。本地部署不了 AI 又想体验的话，欢迎把邮箱发给我/留言也行，免费赠送一个月会员。就当是读者福利了。
