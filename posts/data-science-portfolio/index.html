数据科学家的求职简历作品集

你一般如何获得一份数据科学的工作？精通统计，机器学习，编程在当下是很难获得一份工作的。后来我意识到，少部分人可能有获得工作的技能，但机会没人有作品集。就简历而言，拥有一份作品集证明工作能力，将会是很大的优势。即使你有参考别人的项目，展现你的能力也比告诉别人你能做什么重要。这篇文章讲讲述如何准备数据科学，机器学习，数据分析的简历，什么该放在简历里，什么不应该。以及一些别的注意事项。让我们开始吧！

作品集的重要性

除了通体制作作品集可以学到很多东西，它也可以帮助你获得一份工作。就这篇文章而言，我们把作品集定义为证明你数据科学能力的东西。以 DataCamp 首席数据科学家 David Robinson 在接受采访时所说：

最有效的策略是做一些公共的课题。我在博士期间，做了很多开源项目，并且把它写成了博客。以上内容帮助我证实了我的专业能力。但最为重要的还是另一个公共事业：在博士期间，我在 stack overflow 上很活跃。这家公司的一个工程师在浏览我的一个回答时，他觉得很受用，并且通过社交网络联系上了我。在一些简单面试后，我被雇佣了。

你可能认为这只是巧合的个例，但你经常会发现：你越活越，越有机会遇到这种事。在 David 的博客中写道：

公共的事情你做的越多，就越有机会遇到：某人注意到你的工作，并给到你一个工作机会，并且这安排的面试官还很了解你的工作。

人们经常忘记：软件开发人员和数据科学家也会通过谷歌去解决他们的问题。如果他们通过阅读你的文章解决了问题，他们很可能对你会有个好印象，并且会联系上你。

应该包含在作品集中的内容

数据科学的领域十分之广，从统计到建模，从后台到报表，从 NLP 到 CV，很难确切了解到招聘方需要的是什么。Willian Chen，Quora 数据科学经理在 kaggle 的一次比赛中分享到：

我喜欢看到各式各样的项目，人们在其中倾注精力、挖掘有趣的事情，而不是家庭作业类的项目。喜欢看到较好的文笔表达的有趣的事情，最好配上些可视乎。

很多人都意识到项目的价值，但有一个问题横亘在前：如何获得数据，以及如何利用数据。Jason Goodman，Airbnb 数据科学家，在他的一篇文章中表达了类似的想法并给出建议：

我发现最好的作品集往往很少关注模型，而是更多的在数据上做故事。很多人在财经数据或者Twitter 的数据上做文章，但是他们的数据并没有达到吸引人的地步，这相当于在做无用功。

在文章中，作者提到，网络爬虫是获取数据的一种有利途径。如果你是学生，那就要注意：你的文章就是一个很好的项目，好好打点它。

不应该包含在作品集中的东西

一件我发现的很普遍的事情：大量的简历包含了很多普通的项目。

Jeremie Harris 在文章《4种让你无法受雇数据科学岗位的最快方法》写道：

除了你在琐碎项目上花费的精力，没有什么能更快把你的简历判断为不合适的了。

如果不太理解这句话的意思，下面的这些例子将影响你在面试官心目中的印象：

  • 泰坦尼克幸存者分析
  • 手写数字识别
  • 鸢尾花数据分类

因为上述项目并不能将你从普通人区分开来，下次记得写些新颖的项目。

作品集不是一成不变的

Favio Vazquez 在一篇文章提到他是如何获得数据科学职位的。当然，他的其中一条是有自己的项目。

有自己的项目。如果你在找数据科学的工作，做些真实数据的项目。你可以把他们公开在 Github 上。除了 Kaggle 竞赛外，找些你喜欢的事情或是你想用你的知识解决的事情。

另一件需要注意的是，你必须在找工作过程中不断迭代你的简历。

当你学到新东西或有长进时，就应该更新你的简历。

项目在公开时并没有做完。不要害怕在公开后更新你的项目。
