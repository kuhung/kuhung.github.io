项目 (Projects)

这里整理了我过去做过的一些项目，按量化与金融、链上数据、AI 工具、知识图谱与可视化、媒体与创作、学习与趣味工具六个主题分类。做量化研究、查链上数据、比较模型服务、处理音视频或者学日语时，都可以从对应主题里找。

量化与金融

  • 仓满量化：量化交易学习资料《101 个量化因子解读》和《151 个交易策略》的展示与购买页面。适合想入门因子研究但不知道从哪本书开始的人。https://www.quantfull.com ↗
  • Alpha-Online 量化研究文档从数据获取到因子构建再到回测的完整操作手册，跟着做能跑通一条自己的研究流水线。https://www.quantfull.com/playbook ↗
  • Alpha101 因子三维可视化把 101 个量化因子之间的关系做成可以转动、缩放的三维图。因子研究原本靠公式和表格理解，看图会快很多。https://v.quantfull.com ↗
  • K Online：在线 K 线预测每天自动更新加密货币和 A 股指数的预测结果，同时给出历史走势和预测曲线的对比，方便判断这套方法在什么行情下靠谱。https://k.quantfull.com/ ↗

链上数据

  • LeeOnChain：链上数据分析平台聚合主流资产指标、聪明钱线索、风险地址识别和地址监控，把散在各处的链上信息收到一个界面里。https://leeonchain.vercel.app ↗
  • USDT Wallet DeepLook：TRON 钱包调查工作台输入一个 TRON-USDT 地址，看它的资金流向、关联地址、风险信号和关系图谱。用来查一笔转账到底经过了谁。https://usdt-wallet-deeplook.vercel.app ↗
  • 链上数据挖掘 101 教程面向零基础的链上分析入门，从调 API、追钱包到分析 DEX，一步步带着做。/posts/data-mining-onchain/ ↗

AI 工具

  • PageGrok：端侧浏览器 AI 插件看到什么页面点一下就能问本地 AI，内容不上传，适合处理不想外发的资料。https://www.pagegrok.org ↗
  • LLM Benchmark：大模型推理性能测速像 fast.com 一样打开就能测。对比不同模型服务的首字延迟、生成速度和并发表现，支持 Ollama、vLLM、llama.cpp、LM Studio、MLX。https://benchmark-for-llm.kuhung.me ↗
  • TrakToken：LLM API 价格与成本计算比较各家模型的定价，算清楚你的用量下云端 API 和本地部署哪个更省钱。https://www.traktoken.com/ ↗
  • Phonology AI：语音科学工具集TTS 排行榜、浏览器端声纹比对，外加语音 AI 的原理和术语解释。想搞清楚合成语音好不好、为什么好，从这里开始。https://sheng.kuhung.me/ ↗
  • Visits：Vercel Analytics 的 iOS 客户端把所有 Vercel 项目的访问数据汇总到一个总览页，排出涨得最快的那个，另有十二类细分维度可以下钻。https://visits.kuhung.me ↗

知识图谱与可视化

  • 凡人修仙传人物关系图谱把小说里的人物、门派、地点和事件整理成可交互的关系网，用来看清一部长篇里谁和谁是什么关系。https://fanren.kuhung.me/ ↗
  • LLM Graph：大模型领域知识图谱模型、公司、技术和研究者之间的关系图，用来理清这个领域的脉络。https://llm-graph.vercel.app ↗
  • 后室档案终端 M.E.G.后室（Backrooms）设定资料的离线镜像，收录层级与实体档案，也可以开始一次 NOCLIP 漫游。终端风格界面。https://meg.kuhung.me ↗
  • RAG in LangGraph 入门示例用尽量少的代码跑通 PDF 问答和 ChatPDF 工作流，降低 RAG 的上手成本。https://github.com/kuhung/RAG-in-LangGraph ↗

媒体与创作

  • Fuji LUT for iPhone：富士胶片风格调色给 iPhone 的 Log 视频和照片用的 LUT，导入之后一键得到胶片质感的颜色。https://fuji-lut.kuhung.me ↗
  • 3D Audio Visualizer：三维音频可视化上传音频文件或者直接用麦克风，实时生成三维声音波形动画。https://av.kuhung.me ↗
  • MPEG Zip：苹果录音在线压缩iPhone 录音超过 300M 就传不进 NotebookLM，这个工具压完就能传。https://mpeg-zip.vercel.app ↗
  • Cover Editor：播客封面编辑器上传背景图、改标题、实时预览，导出适配各平台的多种比例封面。https://cover-editor.vercel.app ↗
  • SubPlayer：带字幕的播客播放器字幕和音频波形同步显示，做字幕校对和听力精读都合适。https://sub-player-ebon.vercel.app ↗
  • Podcast RSS Feed：播客订阅源托管自动发布和更新播客 RSS，省掉手写 XML 的麻烦。https://podcast.kuhung.me ↗

学习与趣味工具

  • Vibe Coding 101：零基础用 AI 把产品做到上线写给没有开发背景的人。按定需求、做出第一版、改功能与排错、上线与收费、运行与反馈五个阶段组织，每一步都有具体做法。https://vibe-coding-101.kuhung.me ↗
  • Sakura：日语 EPUB 朗读器上传本地 EPUB 就能朗读，支持进度保存和选词查词，全程在浏览器里跑，文件不上传。https://sakura.kuhung.me ↗
  • Tap：单词与英文肌肉记忆训练给键盘工作者的打字加背单词，在原版基础上加了日语内容、精简了冗余词典。https://tap.kuhung.me/ ↗
  • 出行可达地图：一小时逃离计划输入一个地点，看 15 分钟到 3 小时车程能到哪些地方。周末不知道去哪的时候用。https://keda.kuhung.me/ ↗
  • 夯爆了：拖拽式排行榜输入待排行的内容，拖拽生成 Tier List，排完可以直接分享出去。https://h2l.kuhung.me/ ↗
  • 墨记：水墨低语日记一张永远空白的宣纸，写下心中事，墨迹沉入纸中，回信自纸底洇出。https://wuzi.kuhung.me ↗
  • 每日猜猫病：兽医诊断小游戏扮演兽医，通过对话和症状图片，在限定回合内判断猫可能得了什么病。https://mao.waitlistai.cc/ ↗
  • 性压抑指数测试 SRI性压抑程度的自测量表，给出分数和解读。https://sri.kuhung.me/ ↗
  • JLPT Push：日语语法每日推送定时把 JLPT 语法知识点推到 iOS / macOS 设备上，不用主动去背。https://github.com/kuhung/jlpt-push ↗
