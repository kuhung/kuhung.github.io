项目 (Projects)

AI 工具

  • PageGrok：浏览器 AI 总结侧边栏装完就能用，无需注册与 API Key。在侧边栏一键总结长文、框选重点提问，不离开网页直接问懂它。www.pagegrok.org ↗
  • LLM Benchmark：大模型推理测速工具像测网速一样测大模型速度。一键对比各大本地与云端模型服务的首字延迟、生成吞吐与高并发表现。benchmark-for-llm.kuhung.me ↗
  • TrakToken：大模型 API 价格与性价比对比每天追踪 60+ 厂商、近 700 个模型的输入输出价格与性价比。按你的真实用量算月费，选型不花冤枉钱。www.traktoken.com ↗
  • Visits：Vercel 流量监控 iOS App在 iPhone 上随时随地查看所有 Vercel 项目的访问量走势。一眼锁定涨得最快的产品，支持深度下钻。visits.kuhung.me ↗

量化与金融

  • 仓满量化：系统化量化投研知识库从经典因子剖析到成熟策略回测。深度拆解《101 个量化因子》与《151 个交易策略》，带你构建可落地的量化投研体系。www.quantfull.com ↗
  • Alpha-Online：量化实操流水线手册量化策略实操落地指南。从行情数据清洗、因子构建到策略回测，手把手跑通属于你自己的端到端量化流水线。www.quantfull.com/playbook ↗
  • Alpha101 因子三维图谱告别枯燥的公式和表格。把 101 个经典因子的数学关系映射为可旋转缩放的三维空间图谱，一眼看懂结构。v.quantfull.com ↗
  • K Online：K 线走势量化预测每日自动跟踪 A 股指数与加密货币行情，基于量化模型输出预测曲线，并开放历史走势与命中表现对照。k.quantfull.com ↗

链上数据

  • LeeOnChain：链上异动与聪明钱监控一站式追踪聪明钱动向与大额异动，聚合风险地址识别与钱包监控，洞察链上真实资金流。leeonchain.vercel.app ↗
  • USDT DeepLook：TRON 链上资金穿透追踪输入 TRON-USDT 地址，秒级穿透资金链路、关联地址与风险信号。专为排查资金真实去向设计。usdt-wallet-deeplook.vercel.app ↗
  • 链上数据分析实战教程零基础上手链上分析。从接口调用、钱包追踪到 DEX 资金异动排查，手把手带你跑通真实案例。kuhung.me ↗

知识图谱与可视化

  • 凡人修仙传人物关系图谱把小说里的人物、门派、地点和事件整理成可交互的关系网，用来看清一部长篇里谁和谁是什么关系。fanren.kuhung.me ↗
  • LLM Graph：大模型技术演进图谱一图看懂大模型行业全貌。直观梳理主流模型、底层技术、核心机构与顶尖研究者之间的演进网络。llm-graph.vercel.app ↗
  • 后室档案终端 M.E.G.后室（Backrooms）设定资料的离线镜像，收录层级与实体档案，也可以开始一次 NOCLIP 漫游。终端风格界面。meg.kuhung.me ↗
  • LangGraph RAG 实战脚手架极简代码跑通文档问答与智能检索，开箱即用，快速搭建可靠的 Agentic RAG 工作流。github.com/kuhung/RAG-in-LangGraph ↗

媒体与创作

  • Fuji LUT for iPhone：富士胶片风格调色给 iPhone 的 Log 视频和照片用的 LUT，导入之后一键得到胶片质感的颜色。fuji-lut.kuhung.me ↗
  • 3D Audio Visualizer：三维音频可视化上传音频文件或者直接用麦克风，实时生成三维声音波形动画。av.kuhung.me ↗
  • MPEG Zip：苹果录音在线压缩iPhone 录音超过 300M 就传不进 NotebookLM，这个工具压完就能传。mpeg-zip.vercel.app ↗
  • Cover Editor：播客封面编辑器上传背景图、改标题、实时预览，导出适配各平台的多种比例封面。cover-editor.vercel.app ↗
  • SubPlayer：带字幕的播客播放器字幕和音频波形同步显示，做字幕校对和听力精读都合适。sub-player-ebon.vercel.app ↗
  • Podcast RSS Feed：播客订阅源托管自动发布和更新播客 RSS，省掉手写 XML 的麻烦。podcast.kuhung.me ↗

学习与趣味工具

  • Vibe Coding 实战课：零基础用 AI 一个人做出上线产品不用懂代码。从配置工具、做出第一版到上线收费，带你用自然语言把真实想法做成能用的独立产品。vibe-coding-101.kuhung.me ↗
  • Sakura：日语 EPUB 朗读器上传本地 EPUB 就能朗读，支持进度保存和选词查词，全程在浏览器里跑，文件不上传。sakura.kuhung.me ↗
  • Tap：键盘盲打与词汇记忆训练一边练打字，一边形成词汇肌肉记忆。专为键盘重度用户设计，支持英语与日语词库。tap.kuhung.me ↗
  • 出行可达地图：一小时逃离计划一小时逃离上海 / 北京 / 深圳 / 广州 / 杭州。输入出发地，看 15 分钟到 3 小时车程能到哪些地方，周末不知道去哪的时候用。keda.kuhung.me ↗
  • 夯爆了：拖拽式排行榜输入待排行的内容，拖拽生成 Tier List，排完可以直接分享出去。h2l.kuhung.me ↗
  • 墨记：水墨低语日记一张永远空白的宣纸，写下心中事，墨迹沉入纸中，回信自纸底洇出。wuzi.kuhung.me ↗
  • 每日猜猫病：兽医诊断小游戏扮演兽医，通过对话和症状图片，在限定回合内判断猫可能得了什么病。mao.waitlistai.cc ↗
  • 性压抑指数测试 SRI性压抑程度的自测量表，给出分数和解读。sri.kuhung.me ↗
  • JLPT Push：日语语法每日推送定时把 JLPT 语法知识点推到 iOS / macOS 设备上，不用主动去背。github.com/kuhung/jlpt-push ↗
